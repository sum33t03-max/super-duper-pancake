# India Space Lab Internship Projects

A portfolio repository containing three projects individually completed by **Sumeet Singh** during a 45-day internship at **India Space Lab** (17 June–31 July 2026).

The repository is intentionally limited to project materials suitable for public sharing. Internship reports and documents containing personal or academic identifiers are not included.

## Projects

| Project | Technologies | Included work |
|---|---|---|
| [CanSat Ground Control Station](projects/cansat-ground-control-station/README.md) | HTML, CSS, JavaScript, Chart.js, Leaflet, OpenStreetMap | Browser-based GCS dashboard with simulated telemetry, charts, GPS-style path display, status indicators and CSV export |
| [Drone Technology Notebook](projects/drone-flight-simulation/README.md) | Python, NumPy, Matplotlib, IPython, ipywidgets | Interactive one-dimensional altitude PID demonstration and a separate two-dimensional autonomous boat guidance demonstration |
| [BlueNinjaFin v2 Rocket Fin Analysis](projects/blueninjafin-rocket-analysis/README.md) | SimScale, FEM, CFD, STL geometry | Rocket-fin STL model and documentation of the analysis work; simulation project exports are not included |

## Run the projects

### CanSat GCS

Open `projects/cansat-ground-control-station/src/index.html` in a modern browser with internet access. Chart.js and Leaflet are loaded from public CDNs. The camera preview requires browser permission and a secure context (HTTPS or localhost).

### Python notebook

Use Python 3 and install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
python -m pip install -r projects/drone-flight-simulation/requirements.txt
jupyter notebook projects/drone-flight-simulation/notebooks/altitude-pid-and-boat-guidance.ipynb
```

The notebook is designed for Jupyter or Google Colab. Run cells from top to bottom. Interactive controls require `ipywidgets` support.

### Rocket-fin geometry

Open `projects/blueninjafin-rocket-analysis/geometry/BlueNinjaFin-v2.stl` in compatible CAD or mesh-viewing software. The STL is geometry only; it does not contain the simulation setup or result data.

## Technical scope and limitations

- **CanSat:** The browser dashboard generates simulated telemetry. It has no radio, serial or network connection to a physical CanSat. Mission-control buttons change the interface only; they do not actuate hardware. The camera control previews the computer's local webcam, not a payload video downlink. GPS-style coordinates are generated by the simulation.
- **Drone notebook:** The included notebook contains a simplified one-dimensional altitude PID demonstration and a separate two-dimensional autonomous boat guidance/path-tracking demonstration. It does not contain a complete 6-DOF quadcopter rigid-body implementation. The notebook was run cell-by-cell and also with a fresh-runtime sequential Run All in Google Colab, as confirmed by the author.
- **Rocket analysis:** The repository includes the STL geometry and documentation. SimScale solver projects, mesh exports, boundary-condition files and numerical result exports are not included, so the FEM/CFD analyses cannot be independently rerun from this repository alone.

These boundaries are stated so that the repository describes the included artifacts accurately.

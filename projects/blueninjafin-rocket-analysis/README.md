# BlueNinjaFin v2 Rocket Fin Analysis

An individually completed rocket-fin geometry and simulation-analysis project from the India Space Lab internship.

## Included

- `geometry/BlueNinjaFin-v2.stl` — supplied STL model of the BlueNinjaFin v2 swept-back fin.

## Analysis work

The project work documented during the internship covered:

- Static structural analysis using the Finite Element Method (FEM).
- Von Mises stress and displacement interpretation.
- Mesh refinement and convergence considerations.
- Aerodynamic Computational Fluid Dynamics (CFD) analysis.
- Velocity, pressure and flow visualization.
- Discussion of structural margin and aerodynamic behavior.

The internship analysis used SimScale. These activities are documented here as work completed by the author; the repository does not include the complete SimScale project or exported solver data.

## Open the geometry

Open `geometry/BlueNinjaFin-v2.stl` using compatible CAD or mesh-viewing software. The model is preserved from the supplied project archive. Confirm units, scale and coordinate convention from the original CAD model before making engineering measurements.

## Reproducibility limitations

The repository does not contain the SimScale solver project, mesh exports, material and boundary-condition setup files, or numerical result exports. Therefore, the FEM and CFD analyses cannot be independently rerun or numerically verified using this repository alone. No numerical performance or safety result is claimed as independently reproduced here.

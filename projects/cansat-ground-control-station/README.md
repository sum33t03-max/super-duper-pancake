# CanSat Ground Control Station (GCS)

An individually developed, browser-based Ground Control Station dashboard created during the India Space Lab internship (17 June–31 July 2026).

## Included

- `src/index.html` — dashboard structure and third-party library references.
- `src/css/styles.css` — dashboard styling and responsive layout.
- `src/js/app.js` — simulated telemetry, charts, map updates, interface controls and CSV export.

## Technologies

HTML5, CSS, JavaScript, Chart.js, Leaflet.js and OpenStreetMap.

## Features in the supplied implementation

- Four telemetry charts: altitude, pressure, descent rate and battery voltage.
- Browser-generated telemetry values and packet counter.
- Leaflet map with generated coordinates, marker and path polyline.
- Four-digit status display with descent-rate threshold checking.
- Attitude/orientation display.
- Telemetry logging and CSV export.
- Local webcam preview using `getUserMedia()`, with a stop action that releases media tracks.
- Start/stop, time-sync display, packet reset and mission-command interface controls.

## Run locally

Open `src/index.html` in a modern browser with internet access. Chart.js and Leaflet are loaded from public CDNs. Webcam access requires browser permission and generally requires HTTPS or localhost.

## Important boundaries

This is a dashboard prototype operating in simulation mode, not a hardware-connected CanSat ground station. It does not receive radio, serial or network telemetry packets. Mission command buttons update the user interface only and do not operate flight hardware. The camera control previews the computer's local webcam, not a payload camera stream. Map coordinates are generated by the browser and are not live GNSS measurements.

Descent-rate status checking is implemented, while other fault states are partly simulated. Command-button status can be overwritten by subsequent generated telemetry updates. These behaviors should not be interpreted as validated flight-safety logic.
